## Strategies

**Frozen baseline.** The Step 4 SGD model is never changed and predicts every test year. This represents a model that is deployed once and never retrained.

**Periodic retraining.** Before each test year, a new SGD model and scaler are fitted using every year available before that test year. The current year is predicted before it can enter training, preventing temporal leakage.

**Incremental adaptation.** An SGD model is initialized on the original training years. For each test year, it predicts first and then receives that year's labeled data through `partial_fit`, simulating an update after labels become available. Its preprocessing scaler remains fit on the original training years so the comparison isolates model adaptation rather than changing both the representation and classifier simultaneously.

## Conclusion

The frozen baseline shows how performance changes when the detector is not updated. Periodic retraining adapts both preprocessing and model parameters to the accumulated data, while incremental SGD adapts parameters without a full retraining cycle. As a general operational consideration, periodic retraining may be preferable when labeled data can be collected in batches, while incremental updates may be useful when updates must be frequent and computationally inexpensive. This experiment measures predictive performance, not operational safety, label quality, or deployment cost; both approaches require monitoring for drift and regressions before deployment.
